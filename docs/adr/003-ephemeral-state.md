# ADR-003 — Локальний каталог і відокремлена чернетка

## Context

Бриф вимагає локальних змін, скасування форми та reset без нового запиту.

## Decision

Zustand тримає поточні товари, незмінний початковий знімок, статус і помилку. useState тримає незбережені поля форми. Лише GET через fetch, без постійного сховища.

## Alternatives

Альтернативи: localStorage або серверний запис суперечать межам першої версії; одна спільна копія для чернетки й товару ламає Cancel.

## Consequences

Product використовує числовий id джерела та поля title, price, thumbnail. Перевіряти response.ok і потрібні поля; status idle/loading/success/error. Початковий знімок не мутувати; reset копіює товари зі знімка. Перезавантаження втрачає зміни. Міграції N/A; точна валідація й поведінка форми під час reset залишаються для специфікації.
