# ADR-002 — Один модуль каталогу

## Context

Один каталог і невеликий обсяг; автор підтвердив структуру.

## Decision

src/features/catalog із api, model, components; src/App.tsx складає один екран, src/styles містить звичайний CSS. Прямі залежності UI → model → api; API не залежить від UI/store.

## Alternatives

Альтернативи: багатошарова універсальна архітектура збільшує кількість абстракцій; один великий компонент змішує запит, стан і форму.

## Consequences

Компоненти PascalCase, змінні й функції camelCase; семантичний HTML, підписані поля, явні типи кнопок. Наявних UI-прецедентів немає; не створюємо shared/ui до появи реального повторення.
