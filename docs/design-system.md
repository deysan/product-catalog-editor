# Design system — Product Catalog Editor

Мінімальна візуальна основа для [карти архітектури](architecture-map.md#frontend--ui-foundation) та [UX-потоків catalog-loading](features/catalog-loading/ux-flows.md). Звичайний CSS, світла тема, системний шрифт. Документ задає правила майбутньої реалізації; код і поточний обсяг функції не змінюються.

## Platform posture

- **Posture:** responsive-both — один екран SCR-01 має працювати на 320 і 1280 CSS-пікселях без горизонтального прокручування.
- Контейнер: максимум 960px, по центру; зовнішні відступи 16px на вузькому екрані й 32px від 640px. Картки: одна колонка за замовчуванням, дві від 640px, три від 960px; проміжок 16px.
- Повні назви переносяться, зокрема довгі слова; текст не обрізається. Порядок карток відповідає джерелу.

## Design tool

- **Tool:** code — правила в цьому документі, можливі Markdown-схеми в `screens.md`; без зовнішніх дизайн-інструментів.
- **Library location:** компоненти функції в `src/features/catalog/components/`, стилі в `src/styles/`; без UI-бібліотек та окремого шару `shared/ui`.

## Token source

Наявна основа: `src/styles/base.css:1` (шрифт і кольори), `src/styles/base.css:7` (крок відступів), `src/styles/base.css:19` (контейнер). Таблиці нижче — джерело погоджених токенів; відсутні CSS-змінні додаються лише під час реалізації в `base.css`, стилі каталогу — у `catalog.css`.

Основний, допоміжний і помилковий текст на поверхні та фоні, білий текст кнопки на обох синіх кольорах мають контраст щонайменше 4.5:1. Контур фокуса має контраст щонайменше 3:1 із прилеглим світлим тлом. Декоративна рамка не позначає доступність дії; стан завжди пояснюється текстом.

| Параметр | Значення / правило |
|---|---|
| Шрифт | `system-ui, sans-serif`; без завантаження шрифтів |
| Основний текст | 16px, міжрядковий інтервал 1.5 |
| Заголовок сторінки / назва товару | 28px / 18px, інтервал 1.3, вага 600 |
| `--space-unit` | `0.5rem` (8px за базового розміру 16px), наявна змінна |
| Відступи | 8, 16, 24, 32px — кратні `--space-unit` |
| Картка / блок стану | Внутрішній відступ 16px; рамка 1px; радіус 8px; без тіні |
| Кнопка | Відступи 8px 16px; радіус 4px; мінімальна висота 44px |

## Interaction & writing conventions

- **Картки:** семантичний список; назва товару — заголовок. Фото з `alt`, що містить назву, вписується через `object-fit: contain` у ділянку висотою 160px. При збої фото там показується «Фото недоступне»; назва, ціна й решта каталогу залишаються доступними. Ціна має два десяткові знаки, без доданої валюти. Картки одного рядка мають однакову висоту за найвищою карткою. Ціна закріплена внизу з внутрішнім відступом 16px; між повною назвою та ціною щонайменше 8px. Вільний простір залишається між назвою й ціною, тому ціни в одному рядку вирівняні.
- **Кнопки:** системний шрифт, явний `type="button"`, білий текст на основному синьому тлі; hover і active використовують темніший синій. Доступна активація Enter і Space. Картки не отримують інтерактивного оформлення чи `tabindex`.
- **Фокус:** `:focus-visible` — суцільний контур 3px кольору `--color-focus` із відступом 3px; не обрізати контейнером і не прибирати без заміни. Після активації retry та приховування кнопки фокус спрямовується на блок стану (`tabindex="-1"`), щоб не втратити позицію; повідомлення з результатом змінюється в цьому самому блоці.
- **Loading:** «Завантаження товарів…» у блоці стану з `role="status"`; область каталогу має `aria-busy="true"`. Без карток, попередньої помилки та кнопки повтору. Достатньо тексту, без анімації чи skeleton.
- **Empty:** «Товарів немає» у тому самому блоці з `role="status"`. Це успішний порожній масив джерела; без карток, кнопки повтору й автоматичного запиту.
- **Error:** «Не вдалося завантажити товари. Спробуйте ще раз.» як повідомлення з `role="alert"`, під ним кнопка «Спробувати ще» з відступом 16px. Без карток і технічних деталей; колір доповнює текст. Retry одразу повертає до loading та приховує кнопку до завершення спроби.
- **Success:** картки замінюють повідомлення очікування; `aria-busy` знімається після завершення будь-якої спроби. Помилки й retry у списку немає.
- **Пошук:** поле на всю ширину, висота щонайменше 44px, відступи 8px 16px, рамка 1px `--color-muted`, радіус 4px. Label над полем із проміжком 8px, до результатів — 16px. Чинний `:focus-visible` збережений; поле й фокус не змінюються під час пошуку. Для непорожнього каталогу без збігів — «За вашим запитом товарів не знайдено» з `role="status"`, без retry. Порожній каталог має пріоритет: «Товарів немає» за будь-якого запиту.
- **Microcopy tone:** короткі українські повідомлення без технічного жаргону; назви товарів зберігаються як у джерелі.

Форми редагування, видалення, скидання та їхня валідація поза обсягом цього документа. Темна тема, маршрути й додаткові екрани не вводяться.
