# Changelog — catalog-loading

## 2026-10-03 — Завантаження каталогу та ручна повторна спроба

**What:** при відкритті застосунок автоматично отримує до 20 товарів із DummyJSON. Картки показують фото, повну назву та ціну з двома десятковими знаками без припущеної валюти. Є стани очікування, порожнього каталогу й помилки з кнопкою «Спробувати ще». Невдале фото замінюється текстом «Фото недоступне», решта картки залишається доступною. Некоректний набір відхиляється повністю; паралельні й автоматичні повторні спроби не запускаються.

**Why:** перший робочий крок навчального редактора дозволяє переглядати товари й розуміти результат запиту — [spec §1–2](spec.md). Межі модуля визначає [ADR-002](../../adr/002-catalog-module.md); каталог і окремий початковий знімок зберігаються лише в пам’яті за [ADR-003](../../adr/003-ephemeral-state.md). Погоджене форматування покриває також великі скінченні ціни, включно з `1e21`.

**How to use:** виконати `npm ci` і `npm run dev`, відкрити адресу Vite. Завантаження починається автоматично; після помилки натиснути «Спробувати ще». Перезавантаження сторінки починає нову сесію. Пошук і локальні зміни належать наступним крокам.

**Operational notes:** міграції, backend і feature flags відсутні. Потрібні Node.js 22.12+ та доступ браузера до DummyJSON і фото. Для відкату — повернутися до попередньої версії застосунку; даних для міграції немає.

**Acceptance criteria delivered:** AC-01–AC-10; [review PASS](./_review/review-2026-10-03.md), [фінальні перевірки та межі](ship.md).

**Delivery:** завершено локально в `feat/catalog-loading`. Публікація, створення PR і злиття відкладені за прямою інструкцією автора.
