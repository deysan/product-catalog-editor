# Context — catalog-loading

## Glossary

- Учасник воркшопу — автор навчального проєкту, який переглядає каталог і практикує Codex та SDD; визначення взято з брифу §3.
- Товар — позиція джерела з числовим ідентифікатором, назвою, ціною та адресою фото; визначення взято з карти архітектури й ADR-003.
- Каталог — поточний набір завантажених товарів у пам’яті вкладки. NOT весь асортимент зовнішнього джерела.
- Картка — представлення одного товару з фото, назвою й ціною.
- Початковий знімок — окрема незмінна копія успішно завантаженого каталогу для майбутнього скидання. NOT поточний каталог, який наступні кроки дозволять змінювати.
- Повторна спроба — нове завантаження після невдалого завершення попереднього. NOT автоматичне повторення або оновлення успішного каталогу.
