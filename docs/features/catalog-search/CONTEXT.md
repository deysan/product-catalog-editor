# Context — catalog-search

## Glossary

- Учасник воркшопу — автор навчального проєкту, який переглядає каталог і практикує Codex та SDD; роль із брифу §3 та catalog-loading.
- Товар — позиція джерела з числовим ідентифікатором, назвою, ціною та адресою фото.
- Каталог — поточний набір завантажених товарів у пам’яті вкладки. NOT весь асортимент зовнішнього джерела.
- Картка — представлення одного товару з фото, назвою й ціною.
- Початковий знімок — окрема незмінна копія успішно завантаженого каталогу для майбутнього скидання. NOT поточний каталог.
- Пошуковий запит — текст поля пошуку; для порівняння ігноруються регістр і крайні пробіли, внутрішні пробіли враховуються.
- Збіг — назва товару містить пошуковий запит як суцільний підрядок без урахування регістру. NOT пошук за ціною, описом або приблизною схожістю.
- Видимий список — обчислений результат пошуку серед поточних товарів у їхньому порядку. NOT окремий збережений каталог.
