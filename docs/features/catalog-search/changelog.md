# Changelog — catalog-search

## catalog-search — локальний пошук за назвою

**What:** Після завантаження каталогу поле «Пошук за назвою» одразу відбирає товари за підрядком назви без урахування регістру та крайніх пробілів. Очищення повертає поточний каталог; відсутність збігів має окреме повідомлення.

**Why:** Допомагає знаходити товари серед завантаженого набору ([spec §1–2](spec.md#1-context)). Пошуковий запит локальний, результати обчислюються з актуальних products; початковий знімок зберігається відповідно до [SAD](sad.md) та [ADR-003](../../adr/003-ephemeral-state.md). Межі модуля — [ADR-002](../../adr/002-catalog-module.md).

**How to use:** Дочекайтеся завантаження та введіть `aPpLe` або `  apple  `. Очистьте поле, щоб побачити всі товари. Запит без збігів показує «За вашим запитом товарів не знайдено»; порожній каталог — «Товарів немає».

**Operational notes:**
- Migration: N/A; постійних даних немає.
- Feature flag / config: немає; нових залежностей і API-запитів через пошук немає.
- Rollback: повернути попередню версію застосунку; відкат даних не потрібний.

**Acceptance criteria delivered:** AC-01–AC-07; докази та межі перевірки — [ship](ship.md#verification).
